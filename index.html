Research Interests

Current Research Directions

Object-Centric 4D Scene Understanding

I am working on object-centric 4D reconstruction, exploring how slot-based representations can be combined with frozen geometric backbones to bridge low-level geometric tracking with high-level object-level scene understanding. The broader motivation is to learn structured scene representations that preserve object identity, motion, and geometry across time.

Generative Modeling and Lifted Representations

I am exploring diffusion/flow-based sampling ideas for reward-tilted distributions and lifted data representations. The core question is whether augmenting data with structured auxiliary variables can make difficult tilted sampling problems more tractable, controllable, and interpretable.

Generative AI for Aerial Perception

I worked with Prof. Fernando De la Torre on using foundation generative models to diagnose and improve aerial-view object detectors. The project studies how controlled synthetic generation can expose systematic detector failures across attributes such as object scale, viewpoint, background, occlusion, and appearance.

Selected Projects

Slot4D: Learning Object Slots for 4D Reconstruction

CMU Capstone · Advisor: Prof. László A. Jeni

Slot4D explores whether object-centric representations can improve dynamic 4D scene understanding. The project builds a pipeline that decomposes multi-view video into per-object latent slots, with the goal of connecting high-level object structure to low-level geometry, motion, and tracking.

I am implementing a Slot Attention-style adapter over frozen geometric backbones. The model groups scene evidence using visual features, predicted geometry, and motion cues, and learns slots that ideally correspond to coherent objects across frames and views. The larger goal is to make 4D reconstruction more interpretable and object-aware, rather than treating the scene as only a collection of low-level points or pixels.

  • Object-centric learning for dynamic multi-view 4D reconstruction.
  • Slot Attention-style grouping over visual and geometric representations.
  • Experiments with frozen geometric backbones, slot supervision, and geometric consistency.
  • Long-term motivation: structured world representations for embodied AI and spatial intelligence.

Cross-Resolution Gaussian Splatting for Hybrid Resolution Photography

CMU Project · Advisor: Prof. Shubham Tulsiani

This project studies 3D Gaussian Splatting in settings where the available images have heterogeneous resolutions. In real capture pipelines, not every viewpoint is equally sharp or high-resolution; a reconstruction model may need to combine low-resolution context with a smaller set of high-resolution images.

I designed a cross-resolution Gaussian Splatting pipeline that fuses heterogeneous image sources while preserving fine detail where high-resolution observations are available. The project explores detail-preserving densification and training strategies for high-fidelity reconstruction under mixed-resolution supervision.

  • Hybrid-resolution 3D Gaussian Splatting pipeline.
  • Fusion of heterogeneous image sources for 3D reconstruction.
  • Detail-preserving densification for sharper geometry and appearance.
  • Research direction connected to efficient 3D representation learning.

Generalizable Single-View Holistic Robot Pose Estimation

CMU Project · Advisor: Prof. Jun-Yan Zhu

This project focuses on estimating robot pose and keypoints from a single RGB/depth observation, with an emphasis on generalizing to unseen robot types. The motivation is to build perception systems that can understand articulated robot structure without requiring extensive real-world annotations for every new robot platform.

I designed a single-view robot pose and keypoint estimation pipeline using synthetic data, domain randomization, and synthetic-to-real transfer. The project combines pose estimation, keypoint prediction, and generalization across morphology, connecting computer vision with robotics perception.

  • Single-view holistic robot pose and keypoint estimation.
  • Synthetic-to-real transfer using domain randomization.
  • Generalization to unseen robot types and articulated structures.
  • Research direction connected to robotics perception and embodied AI.

Generative Scene Forecasting for SLAM

CMU 16-833 Robot Localization and Mapping · Course Project

This project investigates whether generative or predictive scene models can help SLAM under temporally sparse sensing. Traditional scan registration can fail when inter-frame motion is large, observations are missing, or dynamic objects violate static-scene assumptions.

The central idea is to project sparse 3D LiDAR point clouds into structured representations, predict future scene geometry or scene flow, and use the predicted point cloud as a prior for registration. We studied skipped-frame settings and model-assisted ICP-style alignment to understand when learned prediction can make localization and mapping more robust.

  • Predictive scene priors for temporally sparse SLAM.
  • Skipped-frame registration experiments with ICP-style alignment.
  • Connection between classical geometry pipelines and learned generative forecasting.

Action Abstractions and Generalization in Robotic Manipulation

CMU 16-831 Introduction to Robot Learning · Course Project

This project studies how algorithm choice, action representation, and training distribution affect reinforcement learning in robotic manipulation. We compare on-policy, off-policy, and model-based approaches across manipulation tasks, with an emphasis on how different action abstractions change learning efficiency and generalization.

The project evaluates PPO, SAC, and a simplified model-based RL/MPC-style baseline under different control spaces and task settings. The broader question is how to choose action representations that make robotic learning more stable, data-efficient, and transferable.

  • Empirical comparison of PPO, SAC, and model-based control.
  • Study of end-effector vs. joint-space action abstractions.
  • Manipulation tasks including reaching, pushing, and pick-and-place variants.
  • Focus on generalization, training distribution, and failure analysis.
