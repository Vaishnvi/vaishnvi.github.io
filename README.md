# Vaishnavi Khindkar — Personal Academic Website

This is a simple GitHub Pages website for `vaishnvi.github.io`.

## How to publish

1. Create a new public GitHub repository named exactly:

```bash
vaishnvi.github.io
```

2. Download/copy these files into the repository:
   - `index.html`
   - `style.css`
   - optional: `Vaishnavi_Khindkar_CV.pdf`
   - optional: your profile photo

3. Push to GitHub:

```bash
git clone https://github.com/vaishnvi/vaishnvi.github.io.git
cd vaishnvi.github.io
cp /path/to/index.html .
cp /path/to/style.css .
git add .
git commit -m "Create personal website"
git push origin main
```

4. Open:

```text
https://vaishnvi.github.io
```

## Things to customize

- Replace the photo placeholder with your real image.
- Replace publication links with actual paper/code/project URLs.
- Replace the Scholar link with your Google Scholar profile.
- Upload your latest CV as `Vaishnavi_Khindkar_CV.pdf`.
