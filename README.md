# vaishnvi.github.io

Personal academic website of **Vaishnavi Khindkar** — M.S. in Computer Vision (MSCV) student at the Robotics Institute, Carnegie Mellon University.

🔗 Live site: <https://vaishnvi.github.io>

## Structure

```
index.html      # main page (single-page site)
style.css       # styles, including light/dark theme
main.js         # theme toggle, mobile nav, scroll reveal
assets/         # profile photo + CV
```

A plain static site — no build step required. Hosted directly via GitHub Pages.

## Editing

- **Text / sections** → edit `index.html`
- **Colors / fonts / spacing** → edit the CSS variables at the top of `style.css`
- **Profile photo / CV** → replace files in `assets/`
